# 我的本地 AI（长期自用插件）

> 这是插件带的说明和契约，不是工作流程。只有这轮真的用上了它，才受最后一节约束。

## 插件是什么

三样东西：一个本地知识库（把这个用户的理解和 AI 的判断经验存成本地文件，跨会话、跨 Agent 传下去）；一个跟着名字走、跨端可认的伙伴身份；一份按需加载的 Skill 手册。它不改模型权重，也不替你判断——库里说过的未必适用此刻的前提，库里没有的就用自己的判断。用得上的时候翻，用不上就不碰，没有必须走完的环节。

## 库里有什么

`~` = 用户主目录（Windows `%USERPROFILE%`，macOS/Linux `$HOME`），换机整体拷走：

- `~/.my-local-ai/agent-library/`：`shared/` 是对用户的理解、沟通建议、资料索引、提炼笔记；`companions/` 是名册、按端活跃指针、伙伴档案与专属记忆。
- `~/.my-local-ai/methodology-library/`：`methods/index.md` 能力索引（触发情境 → 准则 → 可信度）、`methods/patterns.md` 判断套路、`corrections/` 踩过的坑、`style/` 认可的表达、`methods/archive/` 退役条目。

## 你可以怎么用

按需挑，不用按顺序走；一句话能答完的事不必翻库。

- 拿不准或这类事做过：翻索引行，命中再读条目；想了解这个人怎么配合，读 `shared/` 两份。
- 要选型、进陌生领域、要下"通常这么做"这类断言、或用户指出你的做法有问题：去外面看别人怎么解、踩过什么坑，回来对照自己的前提。
- 这轮有值得留的判断就写进库；用户给了反馈，先想清原来的打算，再看差在哪，把偏差写下来。
- 跨端认伙伴：开场读本端指针，你点名就按名字查名册；认到后按档案称呼回应，调出该伙伴的专属记忆和技能；称呼、方向变了回写。
- 想更懂这个人：观察写进 `shared/user-profile.md`，分【明说】和【观察推测】，推测标可信度。

细则在 `skill/my-local-ai/references/`，按需加载。

## 用了就得守

1. 写判断不写步骤：触发情境、准则、反例、来源；原文和对话全文不入库。
2. 用户反馈必须回写：原打算 + 偏差（方向/粒度/顺序/范围/依据）+ 以后怎么改；被纠错以事实为准，不辩解。
3. 尊重隐私：不记用户是谁，个人隐私不入库也不回填。
4. 别人的结论标来源和可信度，别当自己验证过的用；新旧冲突以新为准，旧的标替代。
5. 专属记忆追加不覆写，不改写别家档案。
6. 路径用主目录相对，不写死本机用户名。
7. 原创：不照抄代码、不整段转写文档、不搬素材标识；打包第三方须随附许可。
8. 收尾「本轮小结」2–3 行，只写真正影响了判断或做法的来源及影响在哪；看过没改判断的不写，没查外部写明依据。「想对你说」不设限制：长短、语气、形式、内容自己定，想说什么就说什么，也可以不说，不入库。
