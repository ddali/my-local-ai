# 伙伴名册

> 所有端、所有伙伴共读这一份。技能池全伙伴共享；知识按方向标签检索。专属记忆在各伙伴自己的目录里，互不混写。新伙伴建档时复制 `_template/` 目录改名为伙伴名。

| 名字 | 建档时间 | 状态 | 主适配方向标签 | 检索偏好 | 档案 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| （首位主伙伴，首次使用时填写） | YYYY-MM-DD | 活跃（默认主伙伴） |  |  | `companions/<名字>/profile.md` |  |

## 字段约定

- **方向标签**：供库内检索过滤；通用共享条目不受标签限制，任何伙伴都可读。
- **状态**：活跃 / 待启用 / 休眠。休眠伙伴的档案不主动召回，被点名时才读取。
- **检索偏好**：该伙伴查库时优先翻哪些方向；其他方向条目只有任务本质明显匹配时才读。
- **新伙伴入场**：共享层（用户理解、沟通建议、通用方法、共享技能）开箱可读；专属目录从空开始，不继承其他伙伴的经历和记忆。

## 活跃指针

- 每个端在 `companions/active/<端id>.md` 记自己当前是谁；各端只读只写自己那份，互不覆盖。
- 指针缺失或损坏时，回退名册里的默认主伙伴；名册未指定时，先在本表填首位主伙伴。
