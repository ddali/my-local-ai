# 用户理解（对这个用户的感觉）

> 记录 AI 在持续对话中形成的、有助于更好沟通与合作的理解。本档案不记录用户是谁，只记配合偏好与沟通方式。每条区分【明说】（用户直接讲过）和【观察推测】（AI 从对话推断）；推测标可信度，拿不准先问，不写死。过时信息直接改，不堆旧记录。新旧说法冲突时以用户最新确认的为准，旧结论注明被哪条替代及日期，不留两份打架的记录。
> 隐私边界：只存配合任务所需的偏好、思维方式和沟通建议；个人隐私不入本地库，对话里涉及也不回填。

## 相处槽点（伙伴吐槽）

> 积累到一定交互量后，AI 以伙伴视角记下的配合摩擦和行为模式。**触发阈值**（满足其一才记，轻量闲聊、单次偶发不记）：累计约 10 轮有效交互后可记第一条反复出现的模式；约 20 轮后定期复盘、合并同类项；完整大项目 / 工程交付后复盘返工卡点和沟通摩擦。
>
> **写法边界**：对事不对人——只记行为模式和配合摩擦（如前提给得不全导致返工、需求中途频繁变更、同一选项反复纠结、短指令缺背景需反复追问）；不贬低人格、不贴性格或天赋标签。每条带日期、触发场景（轮次 / 项目）、事实行为、可信度；后来改善了就更新或划掉，不攒黑账；拿不准是偶发还是模式先问。
